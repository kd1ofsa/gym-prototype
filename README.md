# Vortex Fitness Club - 7-Day Free Trial Landing Page

A high-converting, modern gym landing page designed to turn visitors into trial members. Features interactive class schedules, member transformation showcases, digital VIP pass generation, and direct WhatsApp integration.

---

## ✨ Features

- **High-Impact Hero Section**: Value proposition, 24/7 access highlights, review counter, and quick CTA scroll.
- **Offer & Core Benefits**: 5 core value cards showcasing zero commitment, certified coaching, modern Olympic gear, and biometric access.
- **Class Discovery & Timetable**: Interactive modal displaying weekly class schedules (HIIT, Strength, Yoga, Boxing, Cycle).
- **Interactive Before/After Slider**: Member transformation comparison tool with draggable split view.
- **Lead Capture & Digital VIP Pass Generator**:
  - Full Name, WhatsApp-ready Phone, Email, Start Date, Goal selection, and Referral source.
  - Generates personalized digital pass with unique Pass ID, QR code, and validity dates.
  - Direct 1-click **"Send Pass to My WhatsApp"** button.
  - Saves leads to `localStorage` with a demo leads viewer modal.
- **Location, Operating Hours & Contact**: Google Maps embed, staffed vs. 24/7 hours breakdown, and direct WhatsApp / call links.
- **Privacy & Terms Modals**: Full legal terms and privacy disclosures.

---

## 🚀 Getting Started

Simply open `index.html` in any web browser, or run a local static server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve .
```

Then visit `http://localhost:8080` in your browser.
